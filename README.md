## ✦ v2.2 Statement / 版本特别声明

**中文声明**：
早期测试中，试图用一个合理的方式给会说话的Expie重来一次的机会，但在正式发布时忽略了该功能一部分提示词未做删改和修改窗口，现在这部分被基本剔除了，仅留下了中性化的表达方式和机制，现在如果想用该LLM生成任何无限制内容，需要自己配置，mod本身不会提供任何露骨内容，另外一提默认语言已改为英文，感谢使用。

**English Notice**:
During early testing, we attempted to use an in-universe mechanism to give the talking Expie companion a second chance at survival. However, in the initial releases, a portion of the internal prompt leftovers for this feature was overlooked without an editable configuration window. In version 2.2, all explicit prompt leftovers have been thoroughly cleaned up, leaving only neutral in-universe physiological recovery mechanics and blurred expressions. The mod itself does not provide any explicit or NSFW content out of the box. If you wish to use your LLM for unrestricted generation, please configure the custom prompt fields yourself. Additionally, the default language has now been switched to English. Thank you for your support!

---

## ✦ Key Features / 核心特性

- **LLM-Powered Companion Dialogue**: Connect your favorite LLM API (DeepSeek, OpenAI, Claude, etc.) to give your companion an authentic in-character voice. Features real-time typewriter dialogue.
- **8-Language Seamless Interface**: Fully localized in English (default), 简体中文, 繁體中文, 日本語, Русский, 한국어, Deutsch, and Tiếng Việt.
- **Configurable Prompt Architecture**: All prompt foundations, base rules, output formats, and intimate recovery instructions are fully editable and user-controlled.
- **Dual Companion System & Neural AI**: Cooperative companion support with platformer sensory navigation and body carry/rescue mechanics.

---

## ✦ Installation / 安装说明

1. Ensure **BepInEx 5** is installed in your *Casualties: Unknown* game directory.
2. Download **`CUCompanionV2.2.zip`** from the `release/` directory or releases page.
3. Unpack and copy **`CUCompanion.dll`** into your `Casualties Unknown/BepInEx/plugins/CUCompanion/` folder.
4. Launch the game. Press **`F4`** in-game to configure your LLM API settings and persona.
