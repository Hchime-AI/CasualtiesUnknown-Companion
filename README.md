# Casualties: Unknown · Companion Mod (CUCompanion) v2.0

> An autonomous AI companion mod with LLM-powered dialogue, kinetic platformer navigation, and co-op tactical controls.

## ✦ Overview / 概述

The **CUCompanion Mod** transforms your journey in *Casualties: Unknown* from a solitary struggle into a shared survival experience. Your companion reacts dynamically to your surroundings, injuries, and combat in real-time using large language models (LLM), while possessing an autonomous kinetic AI capable of keeping up with you across harsh terrain.

本模组为《未知伤亡》提供了一套 LLM-talk 故事性对话支持接口，为游戏引入大语言模型驱动的叙事陪伴体验。角色能够根据局内生理伤势、突发事件与生存处境实时做出沉浸式的第一人称剧情回应，让每一次探索都成为独一无二的互动故事。

---

## ✦ Key Features / 核心特性

- **LLM-Powered Companion Dialogue**: Connect your favorite LLM API (DeepSeek, OpenAI, Claude, etc.) to give your companion an authentic in-character voice. Features real-time typewriter dialogue, bodily status perception, and intimate soothing interactions.
- **8-Language Seamless Interface**: Fully localized in English, 简体中文, 繁體中文, 日本語, Русский, 한국어, Deutsch, and Tiếng Việt.
- **P2 Autonomous Platformer AI**: Custom kinetic A* pathfinding with smooth native step-up and momentum jumping — ensuring your companion stays right by your side without erratic leaping.
- **Shadow Jump Observer**: Toggleable cyan trajectory visualizer that tracks and records player jump arcs and physical terrain data in real-time.
- **Smart UI Layering**: The chat log stays out of the way of all native inventory and health panels, but dynamically elevates over loading screens and unconscious blackouts so you never miss a word.
- **Live Stream Danmaku Integration**: Includes a dedicated desktop bridge (`CUStreamHub`) for forwarding live stream comments straight to your companion in-game.
- **Dual Control & Tactics**: Carry your partner, switch manual control, or issue tactical radial commands with dedicated hotkeys.

## ✦ Controls & Hotkeys / 快捷键

| Hotkey | Action / 功能 |
| :--- | :--- |
| **`T`** | Open / close input bar to talk to your companion (打开/关闭打字输入条) |
| **`F4`** | Open / close Mod Settings & LLM Configuration Menu (打开/关闭设置菜单) |
| **`F7`** | Open Native Persona Editor (呼出原生人设面板) |
| **`F8`** | Expand / collapse Dialogue History Log (折叠/展开对话历史面板) |
| **`F9`** | Switch manual control between P1 and P2 in Dual Mode (双人模式切换手操) |
| **`Alt + F9`** | Carry / drop your partner (背起 / 放下同伴) |
| **`Ctrl + F9`** | Grab / release partner's arm (抓住 / 松开同伴胳膊) |
| **`Shift + F9`** | Recall P2 companion to your position (召回同伴) |
| **`4` (Num 4)** | Open Radial Tactical Command Wheel: Stop / Follow / Play (战术指令圆环菜单) |

## ✦ Installation / 安装说明

1. Ensure **BepInEx 5** is installed in your *Casualties: Unknown* game directory.
2. Download **`CUCompanionV2.0.zip`** from the `release/` directory or releases page.
3. Unpack and copy **`CUCompanion.dll`** (and optional `CUStreamHub.exe`) into your `Casualties Unknown/BepInEx/plugins/CUCompanion/` folder.
4. Launch the game. Press **`F4`** in-game to configure your LLM API settings and persona.
